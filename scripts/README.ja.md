# オフライン設計検査

[English](README.md) | [ホーム](../README.ja.md)

リポジトリのルートで `python scripts/check_design.py` を実行します。Draft 2020-12対応の `jsonschema` がある既存Python環境を使います。スクリプトはインストール、外部接続、実験起動、ファイル書込みを行いません。

6件のschema定義、全JSON例、旧run-recordの最小メモリ内試料、経験的検査のみの契約／受領、証明artifactのない未完了形式主張、不正な構造への変更、Markdownローカルリンク先の存在、日英の相互リンク、無効／設計のみの限定的な状態表記を検査します。format検査を有効化し、日時は任意依存なしで通常のRFC3339を検査（閏秒表記は非対応）します。JSONキー重複、非有限数、ローカル以外のschema参照を拒否します。外部URL、Markdownアンカー、翻訳の完全な意味的一致は確認しません。

成功は**文書／schema検査のみ**で、SCIの実行時受入ではありません。記号的artifact IDの解決、発行者認証、正規化manifestのhash計算、隔離・予算の強制、形式証明検査、性能測定はしません。構造の正しい受領を信頼できる結果へ昇格させません。

実行時の要件は[schema境界](../schemas/README.ja.md)を参照してください。この設計変更による依存追加インストールはありません。
